# Flujo del Menú - Chatbot ELECCIA

Guía del usuario sobre cómo navegar por el chatbot ELECCIA del JNE.

---

## 🚀 Inicio

Al conectarte al chat, recibirás un mensaje de bienvenida y el **Menú Principal** con 4 opciones:

```
🤖 ¡Hola! Soy ELECCIA, tu asistente virtual del JNE

Menú principal:
1. Procesos Electorales
2. Organizaciones Políticas
3. Información Institucional
4. Servicios Digitales
```

**Puedes seleccionar una opción escribiendo el número (1, 2, 3 o 4) o haciendo clic en los botones.**

---

## 📅 1. Procesos Electorales

### Opción 1: Cronograma Electoral

**Paso 1:** Selecciona un proceso electoral
- 1. EG.2026
- 2. EMC.2025
- 3. ERM.2022
- 4. EG.2021
- 5. Otros procesos electorales

**Paso 2:** Describe qué información necesitas
- Ejemplo: "¿Cuándo son las elecciones generales?"
- Ejemplo: "¿Cuál es la fecha límite para inscripción de candidatos?"

**Paso 3:** El chatbot te mostrará una lista de hitos encontrados relacionados con tu consulta

**Paso 4:** Selecciona el hito que te interesa (número)

**Paso 5:** Recibirás información detallada del hito seleccionado

**Paso 6:** Te preguntará: "¿Otra consulta?"
- **Sí** → Vuelves al menú principal
- **No** → Finaliza la conversación

---

### Opción 2: Consulta tu Político

**Paso 1:** Escribe el nombre completo del político
- Ejemplo: "Juan Pérez García"
- Mínimo: 1 nombre y 1 apellido

**Paso 2:** El chatbot buscará candidatos con ese nombre
- Si encuentra pocos (≤10): Te muestra una lista para seleccionar
- Si encuentra muchos (>10): Te pedirá el segundo apellido para refinar la búsqueda

**Paso 3:** Si te pidió el segundo apellido, escríbelo
- Ejemplo: "García"

**Paso 4:** Selecciona el candidato de la lista (número)

**Paso 5:** Selecciona la elección del candidato (número)
- Ejemplo: "1. EG.2026"

**Paso 6:** Recibirás información completa del político en esa elección

**Paso 7:** Te preguntará: "¿Otra consulta?"
- **Sí** → Vuelves al menú principal
- **No** → Finaliza la conversación

## 🎮 Comandos Especiales

En cualquier momento puedes usar estos comandos:

### `menu`
- Vuelve al menú principal
- No pierdes tu conversación, solo regresas al inicio

### `adios`, `salir`, `cancelar`
- Finaliza la conversación
- Recibirás un mensaje de despedida

## 🔄 Flujo General

```
INICIO
  ↓
Menú Principal
  ├─→ 1. Procesos Electorales
  │     ├─→ Cronograma Electoral → Seleccionar Proceso → Consultar → Ver Hitos → Ver Detalle → ¿Otra consulta?
  │     └─→ Consulta tu Político → Escribir Nombre → Seleccionar Candidato → Seleccionar Elección → Ver Info → ¿Otra consulta?
  │
  ├─→ 2. Organizaciones Políticas
  │     ├─→ Tipos → Ver Info → ¿Otra consulta?
  │     └─→ Consulta de Afiliación → Ver Info → ¿Otra consulta?
  │
  ├─→ 3. Información Institucional
  │     ├─→ Pleno → Seleccionar Miembro → Ver Info → ¿Otra consulta?
  │     ├─→ Funcionarios → Ver Info → ¿Otra consulta?
  │     ├─→ JEE → Ver Info → ¿Otra consulta?
  │     └─→ Sedes → Ver Info → ¿Otra consulta?
  │
  └─→ 4. Servicios Digitales
        ├─→ Servicios Principales → Seleccionar Servicio → Ver Info + Enlace → ¿Otra consulta?
        └─→ Consulta por Trámite → Describir → Seleccionar Servicio → Ver Info + Enlace → ¿Otra consulta?

¿Otra consulta?
  ├─→ Sí → Menú Principal
  └─→ No → Despedida
```

## 💡 Consejos de Uso

1. **Usa números o botones:** Puedes escribir el número de la opción o hacer clic en los botones que aparecen en pantalla

2. **Navegación fácil:** En cualquier momento puedes escribir `menu` para volver al inicio

3. **Búsquedas específicas:** Para servicios y hitos, sé específico en tu consulta para obtener mejores resultados

4. **Enlaces directos:** Los servicios digitales incluyen enlaces directos que puedes hacer clic para acceder

5. **Múltiples consultas:** Puedes hacer varias consultas en una misma sesión, solo responde "sí" cuando te pregunte si tienes otra consulta
